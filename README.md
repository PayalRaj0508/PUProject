# PUProject
Faculty Easy Soft

## 1. Introduction

In educational institutions, managing student project information, faculty allocation, project groups, review marks, and classroom arrangements can become a complex and time-consuming task when the information is maintained manually. As the number of students, project groups, faculty members, and evaluation activities increases, it becomes difficult to efficiently monitor student progress, analyze performance, and maintain accurate records.

To address these challenges, the **Student Project Management and Analytics Dashboard** has been developed as a web-based dashboard for centralized management and analysis of student project-related information. The system connects with a Google Sheet-based data source and presents the information through an interactive and user-friendly interface. It provides a consolidated view of students, project groups, faculty allocation, project categories, review performance, and classroom/laboratory allocation.

The dashboard provides multiple modules, including **Overview, Groups, Faculty Analysis, and Classroom Allocation**. The Overview section provides student statistics and category-wise analysis, while the Groups section enables analysis of project groups, faculty allocation, group members, and review scores. The Faculty Analysis section provides faculty-wise student and group information along with review-performance analysis.  

The system also supports **interactive filtering and searching** based on course, faculty/guide, project topic, group, student name, enrollment number, and other relevant information. This allows administrators and faculty members to quickly locate specific records without manually searching through large spreadsheets.

For performance evaluation, the dashboard analyzes six review components and provides group-wise and faculty-wise performance statistics. It presents average review marks, total scores, completion statistics, and comparative visualizations to support academic monitoring and decision-making.

Another important feature is the **Faculty → Groups → Students** view, which allows faculty members and administrators to examine project groups and their associated students in a structured manner. The system can also export the faculty, group, and student information into Excel for further academic or administrative use. 

The dashboard further provides a **Classroom/Lab Allocation** facility, where rooms, capacities, and faculty members can be configured and project groups can be distributed among the available rooms and faculty members. The resulting classroom-wise student sheet can be viewed and downloaded for operational use.

Overall, the proposed system aims to transform manually maintained project-management information into an **interactive, centralized, searchable, and analytical platform**. By integrating data visualization, filtering, performance analysis, faculty-group mapping, and classroom allocation, the system can assist academic administrators and faculty members in efficiently monitoring student projects and making data-driven academic decisions.
